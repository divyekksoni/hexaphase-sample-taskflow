# 1 – Planning

**Question this phase answers:** *What are we building, for whom, and why?*

## Deliverables
| File | Contents |
|---|---|
| `vision.md` | The problem, target users, desired outcome, success metrics |
| `requirements.md` | User stories with IDs (`US-01`, `US-02`…) and acceptance criteria |
| `scope.md` | In scope (MVP) / out of scope / future ideas |
| `roadmap.md` | Milestones, or MVP → v1 → v2 |

## Gate (exit criteria)
- [ ] The vision is clear and agreed
- [ ] The MVP scope is defined
- [ ] Every MVP requirement has an ID and acceptance criteria
- [ ] Gate approved in `project-health.md`

## Suggested prompt
> "Interview me one question at a time until you can write vision.md and requirements.md."
